# rdgeneric

> Everyone runs Doom on everything, so I did it with Minecraft. Its very first version, rewritten as one C file with no libraries at all.

October 2026. Section: Things that run where they shouldn't.

## Results

- Plays in a terminal, over telnet, from a 20 KB web page, inside a PDF, and on a bare 486

## Story

I built it in one session on 5 October 2026 to ask whether Minecraft can run anywhere the way Doom does. The core has no includes at all and even carries its own sine and square root.
