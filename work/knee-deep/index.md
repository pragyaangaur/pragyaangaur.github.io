# Knee-Deep in the Mines

> Doom's own game files, merged straight into Minecraft as a mod.

October 2026. Section: Things that run where they shouldn't.

## Story

Doom's levels are read straight from its game files and rebuilt as a world that Steve walks into. One block is 32 Doom units, which makes Steve exactly as tall as the Doom marine.
