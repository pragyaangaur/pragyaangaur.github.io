# Paperlane

> Every morning's new arXiv maths papers, flagged when they ship code or Lean proofs, and readable by your AI agent.

October 2026. Section: Maths.

## Story

I wanted one place to see which new maths papers come with code or Lean proofs. Every signal is computed by plain code with no model, so a bad summary can never fake a flag, and it has been live since 24 October 2026.
