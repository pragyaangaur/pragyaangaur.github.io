# Minecraft Bedrock on macOS

> Bedrock has never had a Mac version. Claude reverse engineered the Windows game in about a day, and now it runs offline on Apple Silicon.

October 2026. Section: Things that run where they shouldn't.

## Results

- A WineGDK bug found on the way, sent upstream with a fix

## Story

On 6 October 2026 I asked whether a Mac version of Bedrock could be made from the Windows game files. By 12 October I had fought the Ender Dragon on my Mac without a single crash.
