# LED Doom

> Doom's first episode on one RGB LED and one button. Possibly the lowest resolution Doom has ever been played at.

October 2026. Section: Things that run where they shouldn't.

## Story

I built it on 5 October 2026, and a test bot that only sees the LED colour clears all eight maps. The Arduino version is a hand port that has never met a real board yet.
