# VIctory for macOS

> An open source runtime for the Xbox Series build of GTA VI, brought to Apple Silicon Macs through Wine and Metal. It never touches a game file, so you bring your own.

November 2026. Section: Things that run where they shouldn't.

## Results

- 90 GitHub stars and 150k+ people reached
- Outside contributors send pull requests, and a volunteer test fleet runs it on real Macs

## Story

I started it on 24 November 2026, on top of Marvisak's VIctory, which runs the Xbox Series build of GTA VI on Windows. I have no game files, so everything is tested with a stand-in program and by volunteers who own the game.
