# Matiks bot

> Matiks asked for my resume and then went quiet, so I built a bot that reads each question off the screen and answers it.

August 2026. Section: Automation.

## Results

- World rank 140,000 to 51 in one evening, and then a call with a founder

## Story

The bot reads each question, solves it, types the answer and starts the next game by itself. It once answered 274 questions across five games without a single failure, and its README asks people to keep it out of ranked games.
