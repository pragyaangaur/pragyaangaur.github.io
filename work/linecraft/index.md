# Linecraft

> A small chip that learns new wire protocols from software, an entry for Jane Street's chip design competition.

November 2026. Section: Random things.

## Results

- Predicts how much clock error a link survives, and the measurement agrees to within 0.4%

## Story

Jane Street asked for one small chip that can learn any wire protocol from software. Linecraft has four tiny processors and a line coder that is a table in hardware, so the toolchain can prove a receiver gets back what the transmitter sent and can build that receiver from the transmit rule alone.
